# Smart-Plant-Watering-System
An Arduino-based Smart Plant Watering System that automates plant irrigation using an RTC module and DHT11 temperature and humidity sensor. The system controls a water pump through a relay module based on scheduled timings and environmental conditions, ensuring regular watering while reducing manual effort. Designed for efficient plant care.

## Objectives
- Automate the plant watering process.
- Reduce manual effort in plant care.
- Monitor environmental temperature and humidity.
- Ensure regular watering at scheduled intervals.

## Hardware Components
- Arduino Microcontroller
- RTC (Real-Time Clock) Module
- DHT11 Temperature and Humidity Sensor
- Relay Module
- DC Water Pump
- Connecting Wires and Power Supply

## Technologies Used
- Arduino IDE
- Embedded C
- Sensor Interfacing
- Real-Time Clock (RTC)
- Embedded Systems

## Working Principle
The RTC module keeps track of scheduled watering times. The Arduino processes the time information and controls the water pump through a relay module. The DHT11 sensor monitors the surrounding temperature and humidity. Based on the programmed conditions, the system automates the watering process.

## Key Features
- Automatic scheduled watering.
- RTC-based time management.
- Temperature and humidity monitoring.
- Relay-controlled water pump.
- Reduced manual intervention.
